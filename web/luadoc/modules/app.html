Module app

The table an app's code returns.

An app's code runs and returns one table describing the app. Only render is required.

return {
  refresh = "30m",
  settings = {
    { key = "location", label = "Location", default = "Seattle" },
  },
  fetch = function(config)
    local r = http.get("https://wttr.in/" .. http.urlencode(config.location) .. "?format=j1")
    return json.decode(r.body)
  end,
  render = function(data, slot, config)
    return ui.text { data.current_condition[1].temp_C .. "°", style = "huge" }
  end,
}

Functions

fetch(config, previous)
Gets the app's data. Optional.

Runs on the app's schedule (refresh), when an instance is saved, and on Fetch now. It may take up to 60 seconds and is the only place http is available. What it returns is stored and handed to render. If it raises an error, the previous data is kept and the error is shown in the UI.

It may say when it runs next with a second result, instead of the app's refresh: { refresh = "5m" } (a duration or seconds, at least a minute) or { refresh_at = t }. A device showing the app comes back just after that fetch, within its own refresh bounds.

Parameters:

  • config table The instance's config.
  • previous What the last fetch returned (nil the first time): to keep what doesn't change, or what failed to load this time.

Returns:

  1. Plain data: tables, strings, numbers and booleans. Store binary data with blob first.
  2. { refresh = … } or { refresh_at = … }.

Usage:

  • fetch = function(config)
  local r = http.get(config.url)
  if not r.ok then error("HTTP " .. r.status) end
  return { image = blob(r.body) }
end
  • -- Finished sessions never change: keep them.
fetch = function(config, previous)
  local done = previous and previous.done or {}
  ...
  local live = session_running(now)
  return { done = done, live = live }, { refresh = live and "5m" or "6h" }
end
render(data, slot, config)
Draws the app.

Runs for every image tephra makes for a device, and for every preview. It must finish within 2 seconds and has no network: do slow work in fetch.

Parameters:

  • data What fetch last returned; nil before the first fetch, or for apps without one.
  • slot Slot The space to draw into.
  • config table The instance's config.

Returns:

  1. ui.Node What to draw: build it with the ui functions.
  2. { redraw_at = t }: when the app should be drawn again, such as the moment a countdown ends or results may be shown (or { redraw = "10m" }, from now). The device is told to come back just after, within its own refresh bounds.

Usage:

  • render = function(data, slot, config)
  return ui.column {
    ui.text { config.title, style = "title" },
    slot.size ~= "small" and ui.text { data.summary, wrap = true } or nil,
  }
end
  • -- Spoilers lift at 16:04:
if time.now() < data.reveal then
  return ui.text "Results at 16:04", { redraw_at = data.reveal }
end

Tables

App
The app table.

Fields:

  • name string Built-in apps only: the name shown in the UI. Apps written in tephra use their Name field instead. (optional)
  • description string Built-in apps only, like name. (optional)
  • refresh string or number How often fetch runs: seconds, or a duration such as "90s", "15m", "1h" or "1d" (at least a minute). A device showing the app refreshes at least this often, within the device's own limits. (default "15m")
  • settings {Setting,...} What a config may set, with defaults. (optional)
  • fetch function Gets the app's data: see fetch. (optional)
  • render function Draws the app: see render.
Setting
One setting an app documents.

Settings are documentation and defaults, not a form: a new instance's config is written from them, and anything a config leaves out takes its default.

Fields:

  • key string The name a config assigns, such as location.
  • label string A short description, written as a comment in new configs. (optional)
  • type string "string", "text", "number", "bool" or "choice"; or one that is checked before the app runs, so a mistake is the config's, by name: "duration" ("6h", "1h30m"; seconds with time.duration), "zone" ("Europe/London", "UTC", "local") or "time" (of day: "16:04"). Documentation only. (default "string")
  • options {string,...} For a choice: the values allowed. (optional)
  • default any The value when a config leaves this out. (optional)
  • help string A longer explanation, also written into new configs. (optional)
Slot
The space render draws into.

Fields:

  • w int Width in pixels.
  • h int Height in pixels.
  • size string "full" (the whole screen), "large" (two thirds), "half" or "small" (a third, a quarter, or a sixth). Use it to show less in small slots.
  • grays int 2 (black and white) or 4 (also dark and light gray), by the device's Grays setting. Images and text use the grays there are on their own; check it only to choose differently, such as a photo only when it can be shown in gray.
