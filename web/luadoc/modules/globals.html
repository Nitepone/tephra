Module globals

Everything else an app can use.

Each config, check, fetch and render runs in a fresh Lua 5.4 state, so nothing carries over between calls except what fetch returns. The standard string, table, math and utf8 libraries are there, and of os only os.time, os.date, os.clock and os.difftime (in the server's timezone; time does more, in any zone). There is no file access, require, io or process control.

tephra adds a few string and table helpers that Lua lacks, listed below. The string ones work as methods too: s:split(",").

Lua's string.upper and string.lower only change the letters A to Z: ("São"):upper() is "SãO". Use utf8.upper and utf8.lower for text with accents.

A call may use up to 64 MB of memory.

blob(bytes)
Stores binary data, such as a downloaded image, and returns a reference to it.

fetch can only return plain data, so binary data goes through here: store it, return the reference, and pass that to ui.image in render.

Parameters:

  • bytes string

Returns:

    string A reference like "blob:3f2a…".

Usage:

    -- in fetch
return { photo = blob(http.get(config.url).body) }
-- in render
return ui.image { data.photo }
sleep(seconds)
Waits. Only in fetch, for spacing requests to an API with a rate limit.

The wait counts against fetch's 60 seconds; one that would pass them is an error.

Parameters:

  • seconds number Fractions work: sleep(0.4).

Usage:

    for i, id in ipairs(sessions) do
  if i > 1 then sleep(0.4) end -- at most 3 requests a second
  ...
end

string.split(s[, sep[, plain=false]])
Splits a string.

Parameters:

  • s string
  • sep string A Lua pattern (or plain text, with plain) to split at. Left out: runs of whitespace, and empty pieces are dropped. (optional)
  • plain boolean Treat sep as plain text. (default false)

Returns:

    {string,...}

Usage:

  • ("a,b,,c"):split(",")   --> { "a", "b", "", "c" }
  • ("  two   words "):split() --> { "two", "words" }

Tables

config
The instance's config, also handed to fetch and render.

It is made by running the instance's config code, whose assignments land in this table:

 location = "Portland"
 units = "imperial"

A config can also return { location = "Portland" }. Anything it leaves out takes its default from the app's settings. If the app has a config check, the check runs next, with this table already in place.
