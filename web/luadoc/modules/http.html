Module http

Web requests.

Only available in fetch.

Requests time out after 20 seconds, and bodies over 16 MB fail. Redirects are followed. An answer with an error status is returned, not raised: check ok.

Functions

get(url[, opts])
Sends a GET request.

Parameters:

  • url string
  • opts Options:
    • headers table Request headers, such as { ["Accept"] = "application/json" }. (optional)

Returns:

    Response

Raises:

When the server can't be reached or the request takes too long.

Usage:

    local r = http.get("https://example.com/data.json")
if not r.ok then error("HTTP " .. r.status) end
local data = json.decode(r.body)
post(url, body[, opts])
Sends a POST request.

Parameters:

  • url string
  • body string The request body.
  • opts table Options, as for get. (optional)

Returns:

    Response

Usage:

    http.post(url, json.encode({ q = "x" }), { headers = { ["Content-Type"] = "application/json" } })
