Module time

Dates, times and time zones.

Times are numbers: seconds since 1970-01-01 UTC, the same as os.time() returns. Store and compare them as numbers, and turn them into text only to draw them, with format.

Every function that takes a zone argument accepts:

  • an IANA zone name, such as "Europe/London", "America/New_York" or "Asia/Dubai", which follows that place's daylight saving time;
  • "UTC";
  • a number of hours from UTC, such as -5 or 5.5, which never changes;
  • "local": the server's zone (tephra's timezone setting, else the system's).

Left out, the zone is "local". Apps whose users may be elsewhere can take a zone in their config and pass it along:

settings = { { key = "zone", label = "Time zone", default = "local" } },
...
ui.text { time.format(data.start, "%a %-d %b %H:%M", config.zone) }

parse(s[, zone="local"])
Reads a date or time.

Understands ISO 8601 / RFC 3339 ("2026-12-06T13:00:00Z", "2026-12-06T17:00:00+04:00", "2026-12-06 13:00", "2026-12-06") and RFC 2822 ("Sun, 06 Dec 2026 13:00:00 GMT"). A text with its own offset (Z, +04:00) means exactly that moment; one without is read in the zone given. A date alone is midnight.

Parameters:

  • s string
  • zone For text without an offset. (default "local")

Returns:

  1. optional int The time, or nil if s can't be read...
  2. optional string ...and why.

Usage:

  • -- Jolpica gives the date and the time apart:
 local t = time.parse(race.date .. "T" .. race.time)
  • local t, err = time.parse(config.start)
 if not t then error("start: " .. err) end
format(t, fmt[, zone="local"])
Writes a time as text, in a zone.

The format is strftime's, such as %Y-%m-%d, %H:%M, %a (Sun), %A (Sunday), %b (Dec), %B (December), %p (AM/PM) and %Z (the zone's abbreviation, such as BST). A - after the % drops the leading zero: %-d gives "6" rather than "06", %-I gives "8" rather than "08".

Parameters:

  • t integer
  • fmt string
  • zone (default "local")

Returns:

    string

Raises:

When the format has an unknown % code, or the zone is unknown.

Usage:

  • time.format(t, "%a %-d %b, %H:%M", "Asia/Dubai")   --> "Sun 6 Dec, 17:00"
  • time.format(t, "%-I:%M %p", "America/New_York")    --> "8:00 AM"

make(parts[, zone="local"])
The time at a wall-clock date and time in a zone.

A reading in the hour skipped when clocks go forward means the same reading an hour later (01:30 becomes 02:30); one in the hour repeated when they go back means the first of the two.

Parameters:

  • parts table year, month, day, and optionally hour, min, sec (default 0).
  • zone (default "local")

Returns:

    int

Raises:

When the date doesn't exist, such as 31 February.

Usage:

    time.make({ year = 2026, month = 12, day = 6, hour = 17 }, "Asia/Dubai")
start_of_day(t[, zone="local"])
The start (midnight) of the day a time falls on, in a zone.

Two times are on the same day when their start_of_day is equal.

Parameters:

  • t integer
  • zone (default "local")

Returns:

    int

Usage:

    local today = time.start_of_day(time.now(), config.zone)
 local tomorrow = time.add(today, { days = 1 }, config.zone)
add(t, amount[, zone="local"])
A time plus (or minus) an amount.

years, months, weeks and days step the calendar in the zone, so a day later is the same time of day even across a change of clocks, and a month after 31 January is the last day of February. hours, minutes and seconds are exact. Negative amounts go back.

Parameters:

  • t integer
  • amount table Any of years, months, weeks, days, hours, minutes, seconds.
  • zone For the calendar steps. (default "local")

Returns:

    int

Usage:

    time.add(t, { days = 1, hours = 2 })
